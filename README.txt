OmAr Academy - Mobile Web App MVP

هذه نسخة أولية تعمل كـ Web App/PWA من الموبايل.
1) ارفع الملفات إلى أي استضافة مواقع تدعم HTTPS.
2) افتح رابط index.html من Chrome.
3) من قائمة Chrome اختر "إضافة إلى الشاشة الرئيسية" لتظهر كتطبيق.

الدفع الإلكتروني في هذه النسخة واجهة فقط. ربط Paymob الحقيقي يحتاج Backend ومفاتيح التاجر، ولا يجب وضع المفاتيح السرية داخل الواجهة.
